# UrbanCanteen Food Ordering System Through QR

## 🌟 Project Overview
**UrbanCanteen** is a digital food ordering system designed to optimize canteen operations in institutions and corporate environments. It allows users to order food, make payments, and track status in real-time via a mobile application integrated with QR-based order fulfillment.

### System Components
1. **User Application** – Browse menus, place orders, and receive a unique QR code for pickup.
2. **Canteen Staff Application** – Manage live orders, scan QR codes, and update order statuses.
3. **Management Dashboard** – Access analytics and insights to enhance operational efficiency.

## ✨ Key Features
- **Cross-Platform (Flutter)**: Works on both Android & iOS.
- **Real-Time Tracking**: Order lifecycle from Pending → Preparing → Prepared → Picked Up.
- **QR Code-Based Pickup**: Ensures quick and error-free delivery.
- **Secure Transactions**: Integrated Firebase Authentication & Payment Gateway.
- **Inventory Management**: Monitor and manage stock effectively.

## 💻 Technology Stack

| Component | Technology | Purpose |
| :--- | :--- | :--- |
| Frontend/Mobile | Flutter Framework | Build User & Staff apps |
| Language | Dart | App logic and UI development |
| Backend | Firebase | Cloud storage and logic execution |
| Authentication | Firebase Auth | Secure sign-in |
| Database | Firebase Realtime DB | Order & menu data storage |
| Cloud Functions | Firebase FCM | Notifications & automation |

## 🚀 Setup & Installation
1. Clone the repository
2. Install Flutter SDK & dependencies: `flutter pub get`
3. Configure Firebase (add `google-services.json` / `GoogleService-Info.plist`)
4. Run using `flutter run`

## 🧠 System Requirements
- **Processor**: Intel i3 or above  
- **RAM**: 6 GB minimum  
- **Disk**: 250 GB available  
- **OS**: Windows/MacOS
